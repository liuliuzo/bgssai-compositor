# AI 模型价格与回执

AI 建议执行前展示服务实际配置模型的 TokenHub 目录字段：倍率、计费单位、价格版本、币种和单价。未配置保持未知，禁止按名称猜测倍率。服务仍使用原固定模型。

每次执行先持久保存用户隔离的 request_id，再请求 Hub；结果和用量列表显示 hub + request_id、原始 token、已折算 token、现金实扣及状态。未知不是零，不再次乘倍率，不改变商业余额。客户端重试同一 request_id 不重放生成。

中断、超时和重启后仅使用原 Hub 和同一密钥的指纹匹配补查。现金非 pending 且 billed_tokens 为非负整数才结束恢复。重启仍需重新登录，历史回执按 issuer/sub 找回。
